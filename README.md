# SECURITY-LOG-ANALYSIS-AND-BRUTE---FORCE-ALERT-INVESTIGATION-

**Project objective:** Identify repeated failed login attempts in sample security logs, investigate whether they indicate a possible brute-force attack, and document the findings and recommended response.

**Description:**
1. Collected and analyzed sample authentication logs to identify repeated failed login attempts and suspicious login patterns.
2. Used Splunk Search Processing Language (SPL) to filter authentication events and summarize failed login attempts by source IP address and username.
3. Examined timestamps, login outcomes, and event frequency to identify potentially suspicious authentication activity.
4. Investigated repeated login failures followed by successful authentication to assess potential unauthorized access.
5. Documented security alerts, investigation evidence, and findings in a structured incident report.
6. Recommended preventive measures, including account monitoring, multi-factor authentication (MFA), and account lockout policies.
